Technical checklist
Fixes and checks — mostly free, some quick
▼
  • Connect Google Search Console — free, essential
    Search Console tells you which keywords you're appearing for, which pages Google has indexed, and flags any crawl errors. In MyWebsite: Marketing → SEO → Google Search Console. Once connected, submit your sitemap.
    FreeEssential
  • Check all pages have unique meta descriptions and titles
    Every page (Home, About, Services, each service sub-page, Contact, each blog post) needs its own unique title and meta description. Google may generate its own if these are missing — and the auto-generated ones are usually worse than well-written ones.
    SEO fundamentals
  • Verify the site loads over HTTPS (padlock icon)
    MyWebsite includes SSL by default — confirm there's a padlock in the browser bar and no mixed content warnings. Google uses HTTPS as a ranking signal.
    2 mins to check
  • Test site on mobile — all text readable, buttons tappable
    Google uses mobile-first indexing — the mobile version of your site is what Google primarily crawls and ranks. Test on a real phone, not just the desktop preview.
    Free5 mins
  • Run PageSpeed Insights test — pagespeed.web.dev
    Enter vernwell.co.uk at pagespeed.web.dev (free Google tool). The main things to fix: image file sizes (compress any over 200kb before uploading), and anything flagged as blocking render. A score of 70+ on mobile is a reasonable target for a MyWebsite build.
    FreePerformance signal
  • Add alt text to all images
    Every image on the site should have an alt text that describes what it shows (and where relevant includes the relevant keyword). In MyWebsite: click the image → Edit → Alt Text. This matters both for accessibility and for image search.
    FreeSEO signal
